  1. Copy the prompt, then open the secure generator and sign in to GitHub.
  2. Tap Run workflow, select main, set mode to prompt, and paste your description.
  3. Run it. GitHub Actions uses the repository's private GEMINI_API_KEY secret, validates the AI-generated scene, and runs reviewed Blender code.
  4. When the build and publish jobs pass, tap Open 3D viewer → Load latest AI-generated model. You can rotate, zoom and clear the model.
